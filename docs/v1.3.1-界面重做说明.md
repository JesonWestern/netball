# NetBall v1.3.1 设置界面重做说明

- 发布日期：2026-11-07
- 变更主题：设置窗口重排 / 可缩放 / GPU 列表可滚动 / 文字不再重叠
- 说明：本文只描述 v1.3.1 相对 v1.3.0 的增量，配置键与功能语义不变。

---

## 1. 窗口尺寸与缩放

| 项 | 旧 | 新 |
|---|---|---|
| 客户区 | 460×546 DIP，固定 | **520×680 DIP**，可拖动缩放 |
| 样式 | `WS_CAPTION \| WS_SYSMENU` | 增加 `WS_THICKFRAME \| WS_MAXIMIZEBOX` |
| 最小尺寸 | 无 | 520×680 DIP（`WM_GETMINMAXINFO`） |
| 放大行为 | 无 | 多余宽高分配给列表、预览面板、GPU 文本框与说明区 |

## 2. 布局问题修复

- **控件登记容量不足**：`State::ctrls[96]` 改为 `[160]`。v1.3.0 四页控件总数已超过 96，尾部控件（如「重新探测」）从未被 `ApplyPage()` 隐藏/重排，会出现在错误页面并压住其他内容。这是「很多文字重叠」的主因之一。
- **说明文字不再用单行 STATIC**：任务栏 / 悬浮球 / 材质页的三段长说明改为 `PaintAll()` 用 `DrawTextW(DT_WORDBREAK)` 自绘，随窗口宽度自动换行。
- **标签统一由布局真源管理**：新增 22 个 `IDC_LBL_*` ID，标签创建改用 `MakeLabel + Reg`，删除 `RegDipFromWindow` 反推坐标的旧路径；以后改布局只改 `ComputeGeo()` 一处。
- **DPI 一致性**：设置窗口只使用「屏幕 DC」一个 DPI 源，`open()` 计算出的 DPI 通过 `g_pendingDpi` 传给 `WM_CREATE`，避免「窗口按 96 创建、布局按 168 计算」导致右侧整块被裁；`WM_DPICHANGED` 按 DIP 目标重算窗口物理尺寸。

## 3. GPU 列表

- 由单行 `STATIC` 改为**只读多行 `EDIT`**：`ES_MULTILINE | ES_READONLY | ES_AUTOVSCROLL | WS_VSCROLL`。
- 显卡多时可上下滚动，文本可选中复制；每次「重新探测」后自动回到顶部。
- 深色背景由 `WM_CTLCOLORSTATIC`（只读 EDIT 走该分支）与 `WM_CTLCOLOREDIT` 提供；边框由 `PaintAll()` 自绘圆角描边。

## 4. 各页布局（DIP）

- 页签：4 个 118×34，间隔 6。
- 常规：形状 / 不透明度 / 背景色 / 文字色 / 刷新频率 / 双预览面板。
- 任务栏：显示开关 / 排版列表（高度随窗口拉伸）/ 6 个操作按钮 / 字号·行距·间距 / 4 张材质卡 / 说明。
- 悬浮球：显示开关 / 排版列表 / 6 个按钮 / 字号·行距·间距·宽·高 / 4 张材质卡 / 说明。
- 材质与数据：两组色调 / 模糊半径 / 圆角 / 两个开关 / 5 张温度来源卡 / GPU 文本框 / 重新探测 / 说明。
- 底部按钮固定在窗口底部，不随内容滚动。

## 6. 构建与验证

```bat
build\build.bat
build\package.bat
```

- 构建零警告；`package.bat` 通过尺寸 + sha256 双校验。
- 验证方法：以 Per-Monitor V2 方式截取四页（`SetThreadDpiAwarenessContext(-4)` + `PrintWindow(PW_RENDERFULLCONTENT)`），确认无文字裁切、GPU 文本框有滚动条、缩放窗口后控件跟随重排。
