# NetBall v1.4.2 变更与升级说明

> 基线：v1.4.1　→　目标：v1.4.2
> 日期：2026-11-07
> 主题：修复 CPU 温度恒为 `--`，新增 CPU / GPU 功率显示
> 原则：**只加不改**——现有功能、外观、默认布局、配置文件格式一律不动

---

## 1. 一句话结论

CPU 温度原来读不到，不是主板没有传感器，而是**非管理员进程查询 ACPI WMI 被拒绝**（`0x80041003`）。
本版改用 PDH 的 `Thermal Zone Information` 计数器（同一份 ACPI 热区数据、免提权），并新增 CPU 封装功率与 NVIDIA 显卡功率。

## 3. 核心修复：CPU 温度

### 3.1 原因（实测）

用与 `sensors.cpp` 完全相同的调用序列复现（`build/_tmp/probe_wmi.cpp`）：

```
ConnectServer     0x00000000
SetProxyBlanket   0x00000000
ExecQuery         0x00000000     ← 误导：WMI 惰性执行
Next              0x80041003     ← WBEM_E_ACCESS_DENIED，实例数 0
TokenElevationType = Limited(3), TokenElevation = 0
```

热区设备本身是存在的（`HKLM\...\Enum\ACPI\ThermalZone\THRM`），只是**拒绝非提权进程**。
AIDA64 之所以能读，是因为它的 manifest 声明了 `requestedExecutionLevel="highestAvailable"`（提权 + 内核驱动读 MSR/SMN）；NetBall 是 `asInvoker`。

### 3.2 方案

改用 PDH：

```
\Thermal Zone Information(*)\High Precision Temperature   （分度开尔文，0.1 K 分辨率）
\Thermal Zone Information(*)\Temperature                  （整数开尔文，回退）
```

同一份 ACPI 热区数据，但走性能计数器通道，**不受 `root\WMI` 类 ACL 限制**。
多热区取最大值；PDH 不可用时才退回原来的 ACPI WMI（提权环境仍有 0.1 K 精度）。

### 3.3 口径声明（重要）

该读数是 **OEM 在 BIOS 里定义的系统热区**（本机 `\_TZ.THRM`，多半是板/壳/EC 侧），
**不是核心结温 Tctl/Tdie**。实测 16 线程满载 90 s 只上升 4 K（336 K → 340 K），
而真实结温应上升 20–30 °C。

因此界面上**仍显示 `CPU 62°C`**，不写"核心温度"；需要真实结温请用 HWiNFO / AIDA64，
或在设置里把温度源改为「仅 HWiNFO」（`tempSrc=4`，走共享内存，已有实现）。

## 6. 已知限制

1. **GPU1/2/3 为虚拟显示驱动**：本机 DXGI 会枚举到 4 个 `0x1002:0x1638`（1 个真实核显 + Oray / GameViewer / MuMu 三个 IDD 虚拟显示），LUID 各不相同，现有去重无效，`gpuCount` 被截到 4。
   本版**未修改枚举逻辑**（遵守"只加不改"），因此 GPU1/2/3 的温度与功率恒为 `--`。GPU0 是真实显卡，数值正确。
   修复方案已备好（SetupAPI 只认 `PCI\` 硬件的设备），建议作为 v1.4.3 的独立修复。
2. **AMD 独显功率**：`ADL2_Overdrive6_CurrentPower_Get` 返回值语义（百分比 / 瓦）无可靠文档，本机无 A 卡无法实测，**不做**。
3. **CPU 功率仅 Windows 11**：依赖 Energy Meter Interface（RAPL）。Windows 10 或无 RAPL 的机器该计数器不存在，显示 `--`。
4. **APU 的 `pkg` 含核显**：`rapl_package0_pkg` 是"封装功率"，含 CPU 核心 + 核显 + SoC，不是纯 CPU 核心功耗。
5. **温度语义**：见 §3.3，是系统热区，不是结温。

## 7. 升级与回滚

- **升级**：直接替换 `NetBall.exe`。旧 `config.ini` 原样可用，布局与设置不变。
- **降级**：旧版本读到 `cpupwr` / `gpuNpwr` 会当作未知 token 丢弃，不崩溃、不影响其它项目。
- **回滚**：保留 `dist\NetBallSetup-1.4.1.exe`；本版源码改动集中在 6 个文件，可按文件回退。
