# NetBall v1.2.0 变更与升级说明

- 发布日期：2026-11-07
- 变更主题：任务栏 / 悬浮球共用排版模型 + CPU/GPU 指标 + 高级材质
- 说明：`docs\交付说明.md`（v1.0.0）与 `docs\v1.1.0-变更与升级说明.md` 为历史记录，本文只描述 v1.2.0 的增量。

## 1. 新增指标

| 指标 | 数据来源 | 采样周期 | 执行位置 | 不可用时 |
|---|---|---|---|---|
| 下行 / 上行 | `GetIfTable2`（沿用 v1.1 去重口径） | `refreshms` | UI 线程 | `--` |
| 内存占用 | `GlobalMemoryStatusEx` | `refreshms` | UI 线程 | `--` |
| CPU 负载 | `GetSystemTimes` 差分 `busy=(kernel-idle)+user` | `refreshms` | UI 线程 | 首帧 `--` |
| CPU 温度 | WMI `ROOT\WMI:MSAcpi_ThermalZoneTemperature`（多热区取最大） | 5 s | 后台线程 | `--` |
| GPU 负载 | PDH `\GPU Engine(*)\Utilization Percentage`，按 LUID 汇总并钳到 100 | 1 s | 后台线程 | `--` |
| GPU 温度 | NVIDIA：NVML（`nvml.dll`，随驱动，免管理员）<br>AMD：ADL2（Overdrive6 → Overdrive5）<br>Intel 核显：无公开接口 | 3 s | 后台线程 | `--` |

- **温度数据源可选**：设置 → 材质与数据 →「温度数据源」= 自动 / 仅系统接口 / 仅外部 LibreHardwareMonitor / 关闭。
  「自动」= 系统接口优先，失败后回退外部 LHM（若用户已运行 LHM 并开启其 WMI 提供程序，命名空间 `ROOT\LibreHardwareMonitor`）。
- 所有传感器调用都在**后台线程**，UI 线程只读快照；失败退避 30 s，绝不阻塞消息循环。
- **只有排版里真的出现温度/GPU 项目时才会加载对应组件**：默认配置（只显示网速）不会加载 WMI / NVML，也不会创建 PDH 查询。

## 2. 共用排版模型

### 2.1 spec 语法

单个 ini 键同时编码「启用集合 + 行归属 + 行内顺序」：

```
'/' 分行，',' 分项目
例： down,up/cpuload/gpu0temp
     → 行1：下行 上行；行2：CPU 负载；行3：GPU0 温度
```

项目 token（13 个）：

```
down  up  mem  cpuload  cputemp
gpu0load gpu0temp  gpu1load gpu1temp
gpu2load gpu2temp  gpu3load gpu3temp
```

### 2.2 约束（`layout_model::normalize` 强制执行）

- 行号连续、空行被删除并压实；**每行至少 1 个项目**；
- **行数 ≤ 显示项目数**；
- 任务栏**最多 2 行**，超出的项目并入第 2 行（不丢项目）；
- 悬浮球行数只受项目数量限制；
- 未知 / 重复 token 丢弃。

### 2.3 默认值

| 表面 | 默认 spec | 效果 |
|---|---|---|
| 任务栏 | `down,up` | 单行两项目 |
| 悬浮球 | `down/up/mem` | 三行，与 v1.1 观感一致 |

## 3. 字体与尺寸

- 可调项：**字号 / 行间距 / 项目间距**（任务栏与悬浮球各自独立）。
  - 字号 = 0 表示「自适应」：任务栏按任务栏高度推算并在放不下时逐级压缩；悬浮球按球体内接文字区域推算。
- 任务栏面板：**尺寸由内容决定**（宽 = 最宽行 + 左右内边距，高 = 行数 × 行高 + 上下内边距），不提供手动宽高。
  内容高于任务栏时**向上凸出**（顶部任务栏则向下），右缘仍锚定 `TrayNotifyWnd.left - 8 DIP`。
- 悬浮球：**宽、高独立可调**（40..400 DIP）；下限 = 当前字号下文字实际占用，低于下限自动抬升。
  形状 0 在非等宽高时是**椭圆**，形状 1 圆角方（半径 = min(w,h)×0.22），形状 2 胶囊（半径 = min(w,h)/2）。

## 4. 材质

| 值 | 名称 | 任务栏 | 悬浮球 |
|---|---|---|---|
| 0 | 纯色 | 半透明圆角底板 | 原有纯色填充（与 v1.1 一致） |
| 1 | 亚克力 | **DWM 真实模糊**（独立玻璃底窗，GPU 合成、运行时零 CPU 开销） | 同左 |
| 2 | 毛玻璃 | 自绘：抓屏 → 3 次可分离盒式模糊（近似高斯）→ 色调 → 形状遮罩 → 高光/内阴影 | 同左 |
| 3 | 无底板 | 只有文字 + 1px 描边 | 只有文字 + 描边 |

- 可调：色调、色调强度、模糊半径（0..40px）、面板圆角（0..40 DIP）、1px 高光描边、顶部高光 + 内阴影。
- 能力探测链：DWM 合成开启 + 系统「透明效果」开启 + `SetWindowCompositionAttribute` 可用 → 亚克力；
  任一不满足 → 自动回退毛玻璃。圆角用 `SetWindowRgn` 裁剪，DWM 模糊随之裁成圆角。
- 毛玻璃结果按 `(矩形, 形状, 圆角, 色调, 强度, 模糊半径)` 缓存；只有几何/主题/材质变化才重抓，
  文本每秒刷新不会触发抓屏。

### 兼容与迁移

- 旧配置可直接加载：缺新键回落默认。
- `tblayout` 缺失时由 `tbshowdown/tbshowup/tbshowmem` 生成（单行，保持 v1.1 观感）；
  `balllayout` 缺失时由 `shownet/showmem` 生成（`down/up/mem` 三行）。
- `ballw/ballh` 缺失时由 `size` + `shape` 推导（胶囊宽 = 高 × 3/2）。
- `cfg::save()` 会由排版**反推写回旧键**（`tbshowdown/up/mem`、`shownet/showmem`），保证降级到 v1.1 仍有合理表现。

## 7. 性能实测

环境：Windows 11 build 26300，3840×2160 @175%，8 核。

| 场景 | 稳态 WS | Private | CPU（单核占比 / 全核占比） | 采样窗口 |
|---|---|---|---|---|
| 默认排版（`down,up`，无温度/GPU 项） | **6.03 MB** | 4.02 MB | **0.037% / 0.005%** | 1514 s |
| 双行 + CPU 负载/温度 + GPU0 负载 + 毛玻璃 | **16.11 MB** | 9.86 MB | **0.522% / 0.065%** | 174 s |
| 全温度项但 `tempsrc=3`（温度关闭） | 10.65 MB | 9.54 MB | — | — |

优化点：
- 后台线程 + 快照发布，慢调用（PDH/NVML/WMI）永不进 UI 线程；
- GDI+ `Font` 按字号缓存、文本宽度按 `(字号, 文本)` 缓存，绘制路径内不再 `new Font` / `CreateDIBSection`；
- 文本指纹 + 布局指纹双重脏检查，数值不变不重绘、不调用 `UpdateLayeredWindow`；
- 亚克力路径由 DWM 合成，运行时零 CPU 模糊开销；毛玻璃结果缓存复用；
- 未显示温度/GPU 项目时不加载 WMI/NVML/PDH（默认配置省下约 30MB）。

## 8. 已知限制

1. **CPU 温度**依赖 ACPI 热区，很多台式机 / 虚拟机没有该热区，会显示 `--`（不会伪造数值）；
   需要更全的传感器时可让外部 LibreHardwareMonitor 运行并开启其 WMI 提供程序。
2. **GPU 温度**：NVIDIA 走 NVML（最可靠）；AMD 走 ADL2（尽力而为，部分驱动/型号不可用）；
   Intel 核显没有公开温度接口，只提供负载。
3. **多 GPU 映射**：DXGI 只提供 LUID，NVML/ADL 按各自枚举序，因此采用「同厂商按枚举顺序对应」。
   单卡与同型号多卡准确；不同型号多卡且驱动枚举顺序不一致时温度可能互换。
4. **亚克力**在「透明效果」关闭、远程桌面、DWM 合成关闭时自动回退为自绘毛玻璃。
5. **毛玻璃**抓的是缓存时刻的桌面背景；换壁纸、任务栏图标大幅变化后需要等几何/主题变化才刷新。
6. 任务栏面板只跟随主任务栏（`Shell_TrayWnd`）；副屏任务栏不显示。纵向任务栏仍为尽力而为。
7. 布局编辑用「上移/下移/行±」按钮，不支持鼠标拖拽排序。
8. 面板高度可超过任务栏（向上凸出），超高时以屏幕工作区为界。
