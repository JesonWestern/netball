# NetBall v1.3.0 变更与升级说明

- 发布日期：2026-11-07
- 变更主题：实时预览 / 材质与温度来源平铺 / 悬浮球固定尺寸 / 全材质高光
- 说明：`docs\交付说明.md`（v1.0.0）、`docs\v1.1.0-*`、`docs\v1.2.0-*` 为历史记录，本文只描述 v1.3.0 的增量。

---

## 1. 设置窗口改为实时预览

- 所有控件（材质、温度来源、形状、透明度、字号、宽高、行距、间距、色调、模糊半径、圆角、排版操作）改动后 **立即作用到桌面悬浮球与任务栏面板**，不再需要先点「保存」。
- 预览路径走新增的 `settings_ui::PreviewFn`：只重绘，不写盘、不重启采样定时器、不重新采样；滑块事件按 16 ms 合并。
- `取消`（以及 ESC / 关闭窗口）会恢复到打开设置窗口前的完整 `AppConfig` 快照；`保存` 才写入 `config.ini`。

## 2. 材质与温度来源改为平铺选择

| 位置 | 控件 |
|---|---|
| 任务栏页 | 纯色 / 亚克力 / 毛玻璃 / 无底板，四张卡片横排 |
| 悬浮球页 | 同上，四张卡片横排 |
| 材质与数据页 | 自动 / 仅内置 / 仅 LHM / 关闭 / HWiNFO，五张卡片横排 |

- 选中态由 `g.cfg` 单一真源驱动，点击即写配置并立即预览。
- 旧的三个 ComboBox（`IDC_TB_MAT` / `IDC_BALL_MAT` / `IDC_TEMPSRC`）已移除。

## 3. 悬浮球固定尺寸 + 字号双向制约

- `render::computeBallSize()` 不再调用 `MinBallSize()`：球体严格等于 `ballw/ballh`，网速数字变长不会让球伸缩。
- 文字放不下时由 `BuildBallContent()` 自动缩小字号（球体不动）。
- 新增两个查询接口：
  - `render::ballMinSizeForFont()`：给定字号下球体最小尺寸（DIP）；
  - `render::maxFontForBall()`：给定球体尺寸下最大字号（DIP）。
- 设置窗口联动：
  - 拖宽高 → 低于字号所需下限时回弹，值标签显示「· 下限」；
  - 拖字号 → 球体跟着放大到能容纳，字号到达球体容量上限时值标签显示「· 上限」；
  - 两个滑块在回弹后会同步到新值，不会出现「拖了却跳回旧值」。
- 桌面悬浮球在拖动滑块过程中连续变化，便于预览。

## 4. 高光 / 内阴影覆盖全部材质

- 新增 `src/surface_style.{h,cpp}`：`drawOverlay()` 提供 1px 白色描边、顶部 7.5% 高光、底部 20% 内阴影，全部裁剪到形状内。
- 悬浮球：`mat 0/1/3` 调用 `drawOverlay()`；`mat 2` 仍由 `glass::frost` 在像素层绘制，避免双重叠加。
- 任务栏面板：同样 `mat 0/1/3` 调用，`mat 2` 沿用 frost。
- `matborder` / `matshadow` 继续作为独立开关；无底板使用更亮的描边（alpha 150）。

## 5. 温度数据源（五种）

| 值 | 名称 | 行为 |
|---|---|---|
| 0 | 自动 | ACPI → HWiNFO → LHM；GPU 为 NVML/ADL → HWiNFO → LHM |
| 1 | 仅内置 | ACPI + NVML/ADL，不加载外部组件 |
| 2 | 仅 LHM | LibreHardwareMonitor WMI |
| 3 | 关闭 | 不加载任何温度组件 |
| 4 | 仅 HWiNFO | HWiNFO 共享内存 |

- 新增 `src/sensors_hwinfo.{h,cpp}`：只读映射 `Global\HWiNFO_SENS_SM2`，按 `HWiNFO_SENSORS_SHARED_MEM2` 布局解析，只接受摄氏度读数；共享内存不可用时 30 s 退避。
- GPU 温度来源优先级：厂商（3）> HWiNFO（2）> LHM（1）；厂商读取失败会降级来源优先级，允许外部源补位，但保留已显示值，避免数值与 `--` 闪烁。
- 默认配置（排版中没有温度/GPU 项目）依旧不加载 WMI / NVML / HWiNFO。

## 6. 配置键（`%APPDATA%\NetBall\config.ini`，段 `[NetBall]`）

v1.2.0 的键全部保留，仅扩展 `tempsrc` 取值：

| 键 | 范围 | 默认 | 说明 |
|---|---|---|---|
| `tempsrc` | 0..4 | 0 | 0 自动 / 1 仅内置 / 2 仅 LHM / 3 关闭 / 4 仅 HWiNFO |

旧配置 `tempsrc=0..3` 语义不变；`4` 为新增值，降级到 v1.2.0 时会被 clamp 成 0（自动）。

## 7. 已知限制

1. HWiNFO 必须在「设置 → Safety」中开启 **Shared Memory Support**，否则该来源显示 `--`。
2. AIDA64 那种直接读 MSR/SMBus 的方式需要内核驱动，本程序不安装驱动；驱动层采集交给 HWiNFO / LHM。
3. ACPI 热区在多数台式机 / 虚拟机上不存在，此时「仅内置」只能拿到 GPU 温度。
4. 亚克力在关闭「透明效果」、远程桌面、DWM 合成关闭时自动回退毛玻璃。
5. 毛玻璃抓的是缓存时刻的桌面背景；换壁纸后需要几何/主题变化才刷新。
6. 任务栏面板只跟随主任务栏；副屏任务栏不显示。

## 9. 验证要点

- 材质：四种材质点击后立即变化；纯色/亚克力/无底板都能看到顶部高光与底部内阴影（开关可关）。
- 尺寸：网速数字在 999 KB/s ↔ 1.0 MB/s 之间变化时球体尺寸不变；拖字号时球体实时变化；拖到边界显示「· 上限 / · 下限」。
- 预览：拖动任意滑块桌面球同步变化；点「取消」恢复打开前状态。
- 温度：`tempsrc=4` 且 HWiNFO 开启共享内存时能读到 CPU/GPU 温度；关闭 HWiNFO 后显示 `--`，不崩溃。
