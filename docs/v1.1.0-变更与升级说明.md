# NetBall v1.1.0 变更与升级说明

- 发布日期：2026-11-06
- 变更主题：任务栏透明文字显示（类酷狗歌词）+ 安装包覆盖升级
- 说明：`docs\交付说明.md` 中的 v1.0.0 验收数据保持原样，作为历史记录；本文只描述 v1.1.0 的增量。

---

## 1. 新增功能：任务栏显示

### 1.1 形态与位置

- 任务栏文字是独立的顶层分层覆盖窗，**不注入 Explorer**、不修改任务栏进程。
- 位置固定在通知区域（时钟）左侧，右边缘与 `TrayNotifyWnd.left` 保持 8 DIP 间距；
  找不到通知区域锚点时，按任务栏右端固定预留宽度兜底。
- 透明无底板，只绘制文字；窗口带 `WS_EX_TRANSPARENT`，点击穿透，不挡任务栏按钮、
  托盘图标和系统托盘操作。
- 字号按任务栏实际像素高度自适应（约 `0.36 × 任务栏高度`，夹在 10~34px），
  可用宽度不足时自动逐级缩小；任务栏换边、分辨率变化、DPI 变化后自动重新定位。
- 深色任务栏自动用白字、浅色任务栏自动用深色字（读取
  `HKCU\...\Themes\Personalize\SystemUsesLightTheme`）；同时绘制 1px 反色柔光，
  保证任意壁纸下可读。手动文字色沿用设置窗的「文字颜色」项。

### 1.2 显示内容

任务栏显示项独立勾选，默认只显示上下行网速：

| 配置键 | 默认 | 含义 |
|---|---|---|
| `tbshowdown` | 1 | 任务栏显示下行速度 |
| `tbshowup` | 1 | 任务栏显示上行速度 |
| `tbshowmem` | 0 | 任务栏显示内存占用百分比 |

文本形如：

```
↓ 12.5 MB/s   ↑ 1.2 MB/s   内存 62%
```

网络无效时显示 `--`；三个显示项全部关闭时不显示任务栏窗口。

### 1.3 显隐与避让

- 设置窗、悬浮球右键菜单、托盘菜单都可以开关「在任务栏显示」。
- 任务栏自动隐藏时同步隐藏；任务栏重新出现后自动显示。
- 全屏应用 / 演示模式（`SHQueryUserNotificationState` 返回 BUSY、
  D3D_FULL_SCREEN、PRESENTATION_MODE）时自动隐藏，退出全屏后恢复。
- Explorer 重启触发 `TaskbarCreated` 后自动重新定位并重申置顶。
- 覆盖窗每 250ms 同步一次几何/可见性；文本、颜色、字号、矩形都未变化时不重绘。

### 1.4 双显示开关

| 配置键 | 默认 | 含义 |
|---|---|---|
| `showball` | 1 | 显示悬浮球 |
| `taskbarshow` | 1 | 在任务栏显示 |

两个开关互相独立：

- 只关 `showball` → 只保留任务栏文字 + 托盘图标；
- 只关 `taskbarshow` → 只保留悬浮球；
- 两者都关 → 缩到托盘图标，右键托盘图标可重新打开。

托盘菜单项「显示悬浮球」与球右键菜单项「在任务栏显示」都带勾选态；改动立即写入
`%APPDATA%\NetBall\config.ini`，重启后保持。

## 2. 配置兼容

`config.ini` 仍位于 `%APPDATA%\NetBall\config.ini`，段名 `[NetBall]` 不变。
v1.1.0 新增 5 个键（见上两节），旧版 15 键配置可直接加载；缺失的新键使用默认值，
不会重置或丢失旧设置。v1.1.0 保存后共 20 个键。

## 3. 界面变化

- 设置窗新增两行：
  - 「显示」：`显示悬浮球`、`在任务栏显示`；
  - 「任务栏项」：`下行`、`上行`、`内存`。
- 设置窗客户区由 384×456 DIP 调整为 384×520 DIP（175% DPI 下物理高约 910px，
  1080p 仍可完整显示）。
- 悬浮球右键菜单由 6 个命令项变为 7 个（新增「在任务栏显示(&K)」）。
- 托盘菜单由 5 项变为 6 项（新增「在任务栏显示(&K)」，「显示或隐藏」改为带勾选的
  「显示悬浮球」）。

## 5. 覆盖升级

### 5.1 安装器保证

- 固定 `AppId = {{8F3A1C2E-5B47-4D9A-9E62-0C7D4B15A8E3}}`（v1.0.0 已使用，未改动）。
- 显式 `UsePreviousAppDir=yes`：升级沿用旧版安装目录。
- 保留 `CloseApplications=yes` / `RestartApplications=no`：安装前关闭正在运行的旧版，
  静默安装不自动拉起。
- 新增 `CurStepChanged(ssPostInstall)`：若 `HKCU\...\Run\NetBall` 已存在，
  将其改写为新 `{app}\NetBall.exe` 路径，避免安装目录变化导致自启失效；
  旧值不存在时不写入，不改变用户的自启选择。
- 配置文件 `%APPDATA%\NetBall\config.ini` 不由安装器触碰，升级后原样保留。

### 5.2 实测（v1.0.0 → v1.1.0，`/CURRENTUSER /VERYSILENT`）

测试方式：先静默安装 v1.0.0 到 `%LOCALAPPDATA%\Programs\NetBall`，再运行
v1.1.0 安装包覆盖安装。

| 检查项 | 结果 |
|---|---|
| 安装目录 | 保持 `%LOCALAPPDATA%\Programs\NetBall`，未新建第二套目录 |
| 卸载项 | HKCU 中同一 AppId 只有 1 个，`DisplayVersion = 1.1.0` |
| 主程序 | 1,069,056 B，sha256 `23ed0e19…a1cf3`，FileVersion 1.1.0.0 |
| config.ini | 升级前后 sha256 完全一致（`e3c06e88…1853e`） |
| 自启路径 | 测试前故意写成 `C:\OldPath\NetBall.exe`，升级后自动纠正为 `{app}\NetBall.exe` |
| 测试安装清理 | 静默卸载后安装目录、HKCU 卸载项、Run 值全部移除，配置目录保留 |

> 说明：本机当前已有一套 **系统级（HKLM / Program Files）v1.0.0** 安装。由于本环境
> 无法应答 UAC，本次覆盖升级实测在 **当前用户（/CURRENTUSER）** 分支完成；两者的
> AppId、`UsePreviousAppDir`、文件覆盖与 `[Code]` 逻辑完全相同。双击新版安装包并在
> UAC 中确认后，会按同样机制覆盖系统级 v1.0.0。

### 5.3 任务栏显示实测

测试环境：Windows 11 build 26300，3840×2160 @175%（任务栏 DPI 168，任务栏高 84px）。

| 检查项 | 实测结果 |
|---|---|
| 位置 | 覆盖窗右缘 = `TrayNotifyWnd.left - 8 DIP`；实测间距 14px（= 8×1.75） |
| 文本 | 透明背景 + 白色文字，截图确认字形像素落在覆盖窗内、不侵入托盘区 |
| 宽度自适应 | 仅网速时窗口约 270px；加入「内存」后自动扩展到约 542px，右缘位置不变 |
| 双显示开关 | 关闭球后球隐藏、任务栏文字保留；关闭任务栏后文字隐藏；两者配置均落盘 |
| 设置窗 | 客户区 672×910px（= 384×520 DIP @175%），新增 5 个勾选项全部可见可用 |
| 资源占用 | 稳态 WS **3.67 MB**、Private **3.08 MB**、平均 CPU **0.021%**（进程运行 122.7s 统计） |
| 自动隐藏 | 开启 `ABS_AUTOHIDE` 并移开鼠标后覆盖窗隐藏；恢复原设置后重新显示，注册表 `StuckRects3` 已还原（byte8=2） |
| 全屏避让 | 全屏窗口下 `SHQueryUserNotificationState=2 (QUNS_BUSY)`，覆盖窗隐藏；退出全屏回到 5 后恢复显示 |

> Explorer 重启后的 `TaskbarCreated` 恢复逻辑已实现，但未在本轮实测中主动重启 Explorer，
> 以避免中断当前桌面会话；该路径与托盘图标的 `TaskbarCreated` 处理方式一致。

## 6. 已知限制

1. 只跟随主任务栏（`Shell_TrayWnd`）；开启「在所有显示器上显示任务栏」时，副屏的
   `Shell_SecondaryTrayWnd` 不显示文字。
2. 纵向（左/右）任务栏为尽力而为：文字改为多行堆叠，宽度不足时隐藏；主流底部/顶部
   任务栏不受影响。
3. 任务栏为浅色/深色自动取色，读取的是系统主题；若使用第三方任务栏美化工具，
   实际底色与主题不一致时可能需要手动指定文字颜色。
4. 覆盖窗位于任务栏上方且点击穿透，文字区域不能右键；所有开关入口在悬浮球右键菜单、
   托盘菜单与设置窗。
5. 当前用户与系统级混装（例如旧版装在 Program Files、新版用 `/CURRENTUSER` 安装）属于
   两种安装模式，Inno 会按当前模式的注册表分支识别，可能并存两套；覆盖升级请保持与
   旧版相同的安装模式（普通双击即可）。
6. 任务栏运行按钮很多时，文字可能与任务按钮视觉重叠；覆盖窗是点击穿透的，不会挡住
   按钮点击，但拥挤时观感会受影响。

## 7. 构建与打包

```bat
build\build.bat
build\package.bat
```

- `build.bat` 输出 `build\out\NetBall.exe`；链接参数保持
  `-Wl,--no-insert-timestamp`，同源码重建哈希稳定。
- `package.bat` 校验主程序尺寸与 sha256 后调用 ISCC，输出
  `dist\NetBallSetup-1.1.0.exe`；成功标志为 `RESULT: OK`。
- 资源与脚本编码约束不变：`.bat` 纯 ASCII、`.iss` UTF-8 with BOM、
  `README.txt` UTF-8 BOM + 全 CRLF。
