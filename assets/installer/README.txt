NetBall 网速悬浮球 v1.4.4 —— 用户使用说明

支持系统：Windows 10（1809 及以上）/ Windows 11，仅 64 位（x64）

一、快速上手
1. 双击 NetBall.exe（安装后可在开始菜单的 NetBall 程序组中启动），
   屏幕上会立即出现一个悬浮球，球内显示实时网速。
2. 左键按住悬浮球拖动，即可移动到屏幕任意位置；松开后位置自动记住，
   下次启动仍在原处。
3. 右键点击悬浮球弹出菜单：设置 / 总在最前 / 开机自启 / 在任务栏显示 /
   重置位置 / 关于 / 退出。
4. 任务栏面板默认开启：网速与内存显示在通知区域（时钟）左侧，不占用任务按钮空间。

二、设置窗口（三页，改动即时生效）
设置窗口分为「任务栏 / 悬浮球 / 数据」三页。两个表面的形状、颜色、浓度、文字色、
材质、模糊、圆角、描边、高光均可独立调节；点「保存」写入配置文件，点「取消」
恢复到打开设置前的状态。
· 任务栏：显示开关、排版编辑器、字号/行距/项目间距、形状（圆角方/胶囊）、
  颜色与浓度、材质、模糊/圆角、文字颜色、描边/高光、系统实时亚克力（实验性）。
· 悬浮球：显示开关、排版编辑器、字号/行距/项目间距、宽高、
  形状（圆/圆角方/胶囊）、颜色与浓度、材质、模糊/圆角、文字颜色、
  描边/高光、系统实时亚克力（实验性）。
· 数据：刷新频率、温度数据源、显卡列表与重新探测。

三、材质（五种，平铺选择、选中即生效）
· 纯色：纯色填充，浓度=不透明度，最省资源。
· 亚克力：抓屏后重高斯模糊 + 磨砂颗粒 + 柔和内阴影，接近磨砂玻璃。
· 玻璃：中等模糊 + 镜面高光 + 边缘折射，能透出一点背后的细节。
· 液态玻璃：更强边缘折射、移动高光带与轻微色散，接近 Apple Liquid Glass。
· 无底板：只显示文字与描边。
「浓度」越高越不透明（亚克力建议 30–55%，玻璃 20–40%）；「模糊」可调 0–40 DIP。
自绘材质每 500ms 自动刷新背景，使用「可见状态抓屏 + 形状掩码补全」，刷新时
不会隐藏窗口、不会打断拖动；背后正在播放的视频不会逐帧跟随。
「系统实时亚克力」是实验开关，仅亚克力材质可勾选；Win11 非激活窗口可能退化为
纯色，失败时自动回退自绘材质。

四、悬浮球尺寸与字号
· 悬浮球宽高固定为设置值（40–400 DIP）；运行期网速数字变化不会改变球体尺寸，
  也不会自动缩放字号。
· 字号按「当前排版的最坏情况」（如 1024 MB/s、100%、100°C）一次性求解，
  换数字不会跳动；字号的上限受球体尺寸制约，值标签显示「· 上限」。
· 选择「胶囊」时若宽高相等，会自动把宽度补成高度的 3:2，保证是横向胶囊。
· 拖动字号/宽高滑块时，桌面悬浮球会实时跟着变化，便于预览。

五、温度与功率数据源
【温度】五种可选：
· 自动：系统热区优先（PDH 性能计数器，无需管理员权限），读不到时依次回退
  HWiNFO 共享内存、LibreHardwareMonitor WMI。
· 仅内置：只用系统热区 + NVML/ADL，不依赖任何外部程序。
· 仅 LHM：读取 LibreHardwareMonitor 的 WMI 提供程序
  （需运行 LHM 并在设置中开启 WMI Provider）。
· 关闭：不加载任何温度组件。
· HWiNFO：读取 HWiNFO 的共享内存（需运行 HWiNFO 免费版，并在
  「设置 → Safety」中勾选 Shared Memory Support）。
说明：「系统热区」是主板 / EC 定义的热区读数，不是 CPU 核心结温（Tctl/Tdie）。
AIDA64 那种直接读 MSR/SMBus 的方式需要内核驱动，本程序不安装驱动；需要结温
请在温度数据源里选「HWiNFO」或「仅 LHM」，由它们完成驱动层采集。
读不到时显示「--」，不会伪造数值。

【功率】（v1.4.2 新增；在排版里添加「CPU 功率」「GPU0 功率」等项目即可显示）
· CPU 功率：Windows 11 的 Energy Meter（RAPL）封装功率，含 CPU 核心、
  核显与 SoC，通常大于单纯的核心功耗。Windows 10 没有该计数器，显示「--」。
· GPU 功率：仅 NVIDIA 显卡（NVML），需要较新的显卡驱动。
· AMD 独立显卡功率本版暂不支持，显示「--」。

六、配置文件与升级
配置文件为 %APPDATA%\NetBall\config.ini，保存形状、排版、字号、宽高、材质、
色调、温度源、位置等。删除整个 %APPDATA%\NetBall 目录可恢复全部默认设置。
覆盖升级：直接运行新版本安装包，不需要先卸载；配置原样保留，新增键自动补默认值。

七、卸载
运行安装目录下 unins000.exe，或在开始菜单 NetBall 程序组点「卸载 NetBall」，
或在 Windows「设置 → 应用」中卸载。卸载时可选择是否保留个人配置。

八、常见问题
1. 悬浮球找不到了？
   右键托盘图标 →「重置位置」；或退出程序后删除 config.ini 再启动。
2. 温度或功率一直是「--」？
   先确认排版里确实添加了对应项目；温度再检查数据源是否选对。
   仍无数据时可开启 HWiNFO 共享内存或 LHM；虚拟机、部分精简系统没有系统热区，
   功率为「--」多半是因为系统不是 Windows 11（无 Energy Meter）。
3. 材质看不出透明感？
   确保「浓度」不要过高（亚克力 30–55%，玻璃 20–40%），并让球体/面板背后有
   可见的桌面或窗口；纯色桌面本身缺少可模糊的细节。系统实时亚克力需要
   Windows 设置 → 个性化 → 颜色 →「透明效果」开启。
4. 会不会影响电脑速度？
   默认配置（只显示网速）常驻内存约 6 MB、CPU 接近 0；只有排版里出现温度/GPU
   项目时才会加载对应传感器组件。
